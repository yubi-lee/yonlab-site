## Release State

YOnLab 홈페이지의 **첫 정식 릴리스**입니다. 기존 Vite + React 단일 랜딩 페이지를 Next.js 기반 멀티페이지 사이트로 전면 교체해 Production에 배포했습니다.

| 항목 | 내용 |
|---|---|
| Framework | Next.js 15 (App Router) · React 19 · TypeScript 5.7 · Tailwind CSS v3 |
| 빌드 | `npm run build` → `output: "export"` → `./out` (전 라우트 정적 프리렌더) |
| 배포 | Cloudflare Worker **`yonlab-site`** — Static Assets, `not_found_handling: 404-page` |
| 자동 배포 | `yubi-lee/yonlab-site` branch `main` push → Cloudflare Workers Builds |
| 서버 런타임 | **없음** (완전 정적) |
| 빌드 산출물 | 약 59MB / 94개 파일 |
| 정적 생성 라우트 | **17개** (+ `404.html`) |

**릴리스 시점 검증**
- 주요 라우트 200 · 없는 경로 404 정상
- 내부 링크·앵커 전수 유효 · 죽은 `#` 링크 0
- 반응형 375 / 768 / 1440px = 39개 조합 가로 오버플로 0
- console error 0 · hydration warning 0
- production build 오류·경고 0

### v1.0 포지셔닝 확정 사항

- **AXSL** = AI eXtensible Service Library. App Store / API Catalog가 **아니며**, 사례 기반으로 필요한 AI를 함께 정의·구현하는 방식으로 설명

## Known Limitations

v1.0 시점에 확인된 제약입니다. 상세 근거는 `docs/WEBSITE_SPEC.md` 6장을 보세요.

### 기능

1. **Contact 폼에 백엔드가 없습니다.** 검증 통과 시 `mailto:` URL을 생성해 메일 클라이언트를 열 뿐이며, 사용자가 직접 발송하지 않으면 문의가 도달하지 않습니다.
2. **OG 이미지가 없습니다.** SNS 공유 시 썸네일이 표시되지 않습니다.
3. `sitemap.xml` · `robots.txt` · 애널리틱스가 없습니다.
4. 다국어 지원이 없습니다 (`lang="ko"` 고정).

### 콘텐츠

5. **Partner Products에 Placeholder 2곳** — 파트너·제품 정보 및 제공·협력 방식 미확보 (`TodoNote`로 명시).
6. **고아 라우트 8개** — 진입 경로 없이 200을 반환하며 구버전 구조 유지.
7. `capabilities` slug(`technical-consulting`) ↔ 표시명(`Engineering Consulting`) 불일치.

### 구조

8. **Solution 상세 5종이 템플릿 없이 각 300–440줄로 복제**되어 있습니다. 공통 섹션 수정 시 5개 파일을 모두 손봐야 합니다.
9. **`MediaFrame` 함수가 4개 파일에 중복 정의**되어 있고 파일마다 `object-fit` 기본값·지원 타입이 다릅니다.
10. **미사용 컴포넌트 17개** + `lib/company.ts`(220줄)가 남아 있습니다.
11. **중복 DOM 2곳** — `Solutions.tsx`(프리뷰), `ContactHeroVisual.tsx`(문의유형 칩). 화면·접근성 문제는 없으나 통합하려면 컨테이너 재설계가 필요합니다.
12. Main Page 카피 일부가 컴포넌트에 하드코딩되어 `lib/content.ts` 단일 소스 원칙에서 벗어납니다.

### 성능

13. **`validation-hero.png` 15.3MB** (5504×3072, 표시 폭 최대 700px). `images.unoptimized: true`라 원본이 그대로 전송됩니다.
14. `private-ai-demo.mp4` 13.3MB. 빌드 산출물 총 59MB.
15. 웹폰트를 `globals.css`의 `@import`로 로드 → 렌더 블로킹 + 외부 CDN 의존. `next/font` 미사용.

### 외부 의존

16. **외부 Demo URL 3종이 `http://` + 고정 IP:포트**(`118.217.226.238:10100`)입니다. 도메인·HTTPS가 아니며 서버 중단 시 CTA가 실패합니다.
17. `public/legal/`의 docx·pdf 원본이 공개 다운로드 가능합니다.

### 반응형 / 접근성

18. `lg`(1024px)가 사실상 유일한 분기점(`lg:` 525회 vs `md:` 48회) → **768–1023px 태블릿 구간이 모바일 레이아웃을 그대로 사용**하는 곳이 많습니다.
19. `faint`·`idle` 색상을 흰 배경 소형 텍스트에 사용하는 구간의 WCAG AA 대비가 미검증입니다.
20. 자동재생 영상 4종과 AXSL 캐러셀에 사용자 제어(재생/정지) 수단이 없습니다.

### 운영

21. **`main` push = 즉시 Production 재배포**입니다.
22. **`cloudflare/workers-autoconfig` 브랜치는 병합하면 안 됩니다** — `/apps/onpersona/privacy/`가 삭제되고 `compatibility_date`가 배포본(2026-08-07)과 다른 2026-05-06으로 되돌아갑니다.
